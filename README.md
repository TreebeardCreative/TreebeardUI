# TreebeardUI

TreebeardUI is a shared interface library used by World of Warcraft addons to create settings controls, navigation, styled panels, and movable windows.

## Who needs it?

Install TreebeardUI when another addon lists it as a required dependency. TreebeardUI does not add a separate HUD or settings window by itself; the addon that depends on it provides the content and settings.

## Install

1. Download a TreebeardUI release supported by your game client.
2. Extract the `TreebeardUI` folder into the client's `Interface/AddOns` folder.
3. Install and enable the addon that requires TreebeardUI.

TreebeardUI is developed for WoW Forever. Retail support and Retail releases are not provided. Other clients are not officially supported.

## Help

For a problem with a TreebeardUI-powered settings page, report the name and version of the addon using it, your game client and version, and the steps that caused the issue. Addon-specific settings and features are handled by that addon.
